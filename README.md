# El consumo de combustible de un motor industrial y Optimización térmica (ThermoWise)

**ThermoWise** es una aplicación web diseñada para el análisis operacional de sistemas térmicos e industriales. El problema principal que resuelve este proyecto es calcular de manera rápida, precisa y automatizada el consumo específico de combustible de un motor industrial y la eficiencia térmica de motores o calderas a partir de datos operacionales básicos, eliminando errores de cálculo manual y facilitando la optimización energética.

---

## 🛠️ Tecnologías y Librerías Utilizadas

* **HTML5:** Estructuración semántica de la interfaz de usuario, formularios de captura de datos operacionales y paneles de resultados.
* **CSS3:** Diseño visual de la interfaz (**ThermoWise**), estilos responsivos y organización estética de los componentes web.
* **JavaScript (Vanilla):** Implementación de la lógica de negocio, validaciones de entrada, fórmulas termodinámicas y manipulación dinámica del DOM sin dependencias externas.
